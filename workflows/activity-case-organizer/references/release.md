# 发布与恢复

## 完整备份

```sh
python3 "$SKILL/scripts/archive.py" backup /素材库/活动 /备份盘/活动-版本.tar.gz
python3 "$SKILL/scripts/archive.py" restore /备份盘/活动-版本.tar.gz /恢复检查/活动
```

备份命令打包全量业务原件及元数据，并在临时目录完整解包逐文件读回校验；旁边生成 `.receipt.json`。恢复只允许新目录，不覆盖现有工作。每次修改后重新备份并确认新版本，旧版本保留。

经目标环境授权的存储工具上传完整备份包及回执到私有备份位置，下载读回并校验 SHA256、字节数与解包清单。不要上传到公共展示素材桶来代替私有备份。保存备份对象 URL/ID、校验值、验证时间与权限范围。云端只有压缩图时明确标“展示备份”，不能通过完整原件验收。

活动数据以外，线上 media-bigapple 的品牌、活动筛选和管理员配置在 SQLite；用工程 `npm run db:backup` 的一致性备份流程，另保存 logo 文件/对象映射。现有运行库不能用仓库 bootstrap 覆盖。若本地拿不到生产管理数据库，交接明确标出缺项，由有权限的管理员备份。

## 版本检查

记录 `approvedArchiveSha256`、`localBackupConfirmedAt`、`localBackupLocation`，以及 `cloud:{sha256,bytes,url,downloadVerifiedAt}`。这些值来自用户确认和实际下载验证，不以脚本自产文字冒充确认。负责人豁免本地额外备份时记录 `ownerWaiver:{name,reason,confirmedAt}`。

```sh
python3 "$SKILL/scripts/release_gate.py" /素材库/活动 /备份盘/活动-版本.tar.gz /工作区/交接确认.json
```

此脚本检查回执与当前完整文件集合、归档哈希是否一致；不鉴别确认者身份，也不替代云端下载实测。完整云端备份或 UI 审阅未完成时可继续本地工作，不宣称可交接。

## 上线

使用既有 bigapple-deploy 当前文档和当前站点身份。部署前保存上一个发布包、源码指纹与 deployment ID；只上传本次确认产物；部署结果未知先回查。实测列表入口、旧 UID 详情地址、图片打开、视频实际播放、网站链接、手机布局、ZIP 完整保存和解压。部署成功不等于 ZIP 已完整保存。

公开 ZIP 只包含页面展示版媒体与已选资料，另附作品/报道链接。它不包含拍摄原片和网站源码，不充当完整备份。大文件下载受浏览器内存、网络和非 ZIP64 格式限制；失败应明确提示，保留重试入口，不能返回缺文件的“成功包”。

更新既有站点时保留 UID、品牌入口和历史活动。发现本地仓库较旧，用实得的当前全站 catalog 作为数据基线；源码来源和抓取日期写入交接记录。跨机器只交接相对路径、原件、元数据和工具包，不绑定作者电脑路径或账号。
