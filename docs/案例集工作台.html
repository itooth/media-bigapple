谁改什么

想改的内容修改位置下一步
照片命名、顺序、封面正式原件当前文件名mirror → catalog → 预览
某张图暂不展示媒体映射 selected + 理由catalog → 预览
活动名称、时间、简介manifestcatalog → 预览
案例名称、简介、网址案例目录、说明.md、linkReviewmirror → catalog → 预览
海报、合作方 logo、课件原件 + manifest.presentationmirror → catalog → 预览
字号、布局、交互网站 EventDetail / CSSbuild → 预览；素材不重做
品牌 logo、入口筛选既有管理后台和数据库备份配置；保留入口身份

新手只需要完成的动作

1. 发来素材文件夹。

2. 补充素材里找不到的关键事实。

3. 打开预览，指出需要改的图片或文案。

4. 确认当前页面内容。

5. 告知原件备份位置；负责人豁免要明确说明。

6. 确认发布对象，或按交接说明自己推送仓库。

脚本、哈希、压缩、JSON 和上传回执由助手处理。新手不需要手填技术字段。

已定边界

- 没海报沿用现有封面；缺 logo/课件省略；未知事实保持空值。

- 同主题图片、网站、视频分别保留；标题相似不等于同一案例。

- 重跑按内容哈希复用 AI 判断与压缩；用户当前命名优先。

- 归档输入保留；旧版本进历史目录，不能误当成新案例。

- 原件丢失从完整云备份恢复；展示压缩图无法冒充原件。

- ZIP 是页面展示素材包，完整原件备份另外保存。

- 上传失败/结果不明先回查；不能把缺文件包标成成功。

- 标准化发布仍需用户授权；本次用户选择自行推送，未执行推送或上线。
