# 案例去重与图片下载修复

基线：2c1d2a2，其原始 dist/index.html 与调查时线上 HTML 字节一致。
分支：codex/case-cards-download。仅本地修改，未推送或发布。

## 修改

- 图片案例卡片保留截图预览和轮播，将对应网站链接放进同一卡片，取消重复的网站卡片。
- 只有网站链接的案例继续独立展示；同名不同案例不按名称合并；完整网址清单继续用于批量下载说明。
- 图片查看器中的“保存图片”读取图片后直接下载，使用可读名称，多图增加序号。
- 下载中避免重复点击；失败可重试；关闭或切换图片取消未完成读取。
- 根据实际文件头优先确定格式，兼容历史 JPEG 被图床标记为 PNG 的情况；原文件字节不变。
- 保持活动现场图片在上、案例在下的布局。未调整加载策略、后台、生产数据或图床对象。
